### This repository hosts the [HTML Standard](https://html.spec.whatwg.org/).  

<br>

<details open>  
  <summary>What is HTML Standard?</summary>  

<ul>
  <li>The HTML Standard is the official, continuously updated specification for HyperText Markup Language (HTML)</li>
  <li>It is updated continuously by the open source community of <a href="https://github.com/whatwg">WHATWG<a> </li>
</ul>  

</details>

### Code of conduct  

We are committed to providing a friendly, safe and welcoming environment for all. Please read and respect the [WHATWG Code of Conduct](https://whatwg.org/code-of-conduct).

### Contribution opportunities

We appreciate all contributions, see the [guidelines for contributing](.github/CONTRIBUTING.md) for details, including information on how to build HTML output from the `source` file so you can preview your changes locally.
